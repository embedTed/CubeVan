# CubeVan
Onboard Vanlife computer mimicking a space CubeSat onboard computer 


# CubeVan OC (onboard computer) starter kit
1. MCU capable of running multiple peripherals
2. IMU sensor
3. GPS module
4. Screen

# CubeVan requirements 
- IMU sampling:            100 Hz
- Attitude update:         50 Hz
- Dashboard telemetry:     5 Hz
- Touchscreen refresh:     20-30 FPS
- Battery measurement:     10 Hz
- Environmental sensors:   1 Hz
- Telemetry logging:       1 Hz 
- CPU target:              below 60% sustained
- Boot time:               below 3 seconds
- Sensor timeout detect:   below 2 seconds
